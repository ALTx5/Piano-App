# Keynote

A focused, dependency-free piano sight-reading trainer.

## Run it

Open `index.html` in any modern browser. No install or build step is needed.

Choose multiple choice, fill-in-the-blank, or major-scale practice; select treble, bass, or both clefs; and start practicing. Scale rounds cover all 12 major scales, display the complete ascending scale on the staff, and ask you to identify its name. You then play every key of the scale in ascending order on the piano. After a correct performance, standard ascending right-hand fingering appears for treble-clef rounds and left-hand fingering appears for bass-clef rounds (1 is the thumb and 5 is the pinky).
